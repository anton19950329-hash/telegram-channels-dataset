# Датасет Telegram-каналов — Портал TG

Открытые данные каталога [Портал TG](https://portal-tg.online/): 5242 публичных Telegram-каналов в 20 темах со статистикой — подписчики, частота постов, просмотры и охват.

Обновлено: 2026-10-07. Обновляется раз в неделю.

## Файлы

- `channels.csv` — каналы, по строке на канал.
- `categories.csv` — темы: число каналов и суммарная аудитория.

## Поля `channels.csv`

| Поле | Что это |
|---|---|
| slug | адрес карточки в каталоге |
| title | название канала |
| handle | @имя в Telegram |
| telegram_url | ссылка на канал |
| category | тема каталога |
| subscribers | подписчики на дату выгрузки |
| posts_per_week | постов в неделю |
| avg_post_views | медиана просмотров поста за последние 30 дней |
| reach_percent | avg_post_views / subscribers, % |
| last_post_date | дата последнего поста |
| catalog_url | карточка канала с историей подписчиков |

Пустое значение — данных нет: у канала закрыта лента или слишком мало свежих постов.

## Как собраны данные

Подписчики берутся каждую ночь с публичной страницы канала в Telegram, посты и просмотры — раз в неделю по открытой ленте. Подробная методика — на странице [«О каталоге»](https://portal-tg.online/o-kataloge).

В датасет не входят каналы для взрослых, закрытые каналы и боты.
